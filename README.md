# Expo Planner

A web app for planning and organizing trade expo participation, with spreadsheet-style planning tools and an integrated AI assistant.

## What it does

- Authenticated user accounts (NextAuth)
- Spreadsheet-style planning interface (Fortune-Sheet)
- AI assistant (Claude) for planning help
- Persistent data via PostgreSQL (Prisma ORM)

## Stack

Next.js 14 · TypeScript · Prisma · NextAuth · React · Anthropic Claude API
